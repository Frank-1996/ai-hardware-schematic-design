# AI 辅助硬件原理图设计

这是一个中文实践指南，面向使用 KiCad 等 EDA 工具绘制原理图的工程师和学习者。用 AI 整理需求、提取数据手册约束、草拟连接表和辅助审查，由设计者核对器件资料并验证实际电路。

## 工作流程

1. **定义约束。** 记录输入电压范围、各路电源负载、接口电平、环境条件和成本目标。把缺失信息列为待确认项。
2. **整理器件依据。** 提供厂商数据手册、参考设计和准确订货型号。让 AI 输出引脚连接草案，并为每条关键结论记录资料版本及页码、表号或章节。
3. **绘制原理图。** 在 EDA 中按电源、控制器和接口分块绘制。对照实际封装核对符号引脚号和封装焊盘号。
4. **审查并验证。** 运行电气规则检查（ERC），逐条处理告警并记录有意例外。复核 ERC 无法覆盖的额定值、时序及热设计。打样后记录上电、各路电压和接口功能的实测结果。

## 可复制的提示词

> 我在设计一块低压传感器板。以下是需求、器件完整型号及厂商资料片段：[粘贴材料]。请输出表格：位号、引脚号、引脚名、目标网络、连接理由、资料出处、待确认项。先列出材料缺失或冲突的地方。没有资料支撑的引脚号和元件值标记为“待核对”。最后列出 ERC 之外需要人工检查的项目。

## 示例：审查 I²C 传感器接口

把主控与传感器的准确型号、供电电压、目标总线速率及预计总线电容交给 AI。请它定位 SDA、SCL 和地址配置引脚，检查两端逻辑阈值，并根据上升时间与器件允许的灌电流估算上拉电阻范围。把连接和计算逐项对照数据手册，打样后用示波器检查上升时间和低电平。

## 原理图审查清单

- [ ] 电源范围、电流预算和器件降额有计算或资料支撑。
- [ ] 去耦、上电时序、复位和启动配置已对照数据手册。
- [ ] 接口电平、上拉、终端和保护器件按实际使用条件复核。
- [ ] 连接器方向、引脚编号和符号到封装的映射已确认。
- [ ] ERC 问题已解决或记录理由，关键网络有测试点或测量方法。
